#
# ---------------------------------------------------------------------------
# KEY VERB ARGV GRAMMAR -- LEGACY (0.1.8)
#
#   ydotool key [--delay <ms>] [--key-delay <ms>] [--repeat <times>] \
#               [--repeat-delay <ms>] <key sequence> ...
#
#   <key sequence>  =  one combo: key and modifier NAMES joined with '+',
#                      e.g. "alt+r", "CTRL+alt+f3", "ctrl+Backspace"
#   NOT the <KEYCODE>:<PRESSED> pair syntax -- that is the 1.0.x (modern)
#   dialect; see ydotool_key_usage_modern.txt.
#   Names are resolved against the client's built-in tables; an unknown name
#   aborts with "no matching keycode" (upstream v0.1.8 Tools/Key/Key.cpp
#   throws std::invalid_argument at that message).
#   `key` is the only verb with --repeat/--repeat-delay in this dialect.
# ---------------------------------------------------------------------------
